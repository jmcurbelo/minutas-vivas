# Minutas vivas

Proyecto de la asesoría **"De la idea al producto con IA"**: una aplicación web para llevar los compromisos de cada reunión, construida con Claude Code.

## Contenido

| Carpeta | Para qué |
|---|---|
| `kit/` | **Kit de arranque**: cópialo a tu propio repositorio y pídele a Claude Code que construya la aplicación |
| `referencia/` | **Versión terminada y probada**: el destino al que llegamos; sirve de guía y de respaldo |

## Construir tu propia versión con Claude Code

1. Crea un repositorio vacío en GitHub y ábrelo en Claude Code.
2. Copia ahí el contenido de `kit/` (incluida la carpeta oculta `.claude/`).
3. Pídele a Claude:
   - *"Prepara mi Mac para este proyecto"* → instala Homebrew, git, uv y Mailpit.
   - *"Lee la especificación y propón un plan"* → revisas el plan y lo apruebas.
   - *"Constrúyelo, ejecuta los tests y arráncalo"*.
4. Personalízalo: pídele cambios en lenguaje natural.
5. Guarda cada avance: *"Haz commit y súbelo a GitHub"*.
